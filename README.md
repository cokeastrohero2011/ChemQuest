# TGA ChemQuest: Molecular Arena

TGA ChemQuest is a browser-based chemistry app that uses OpenAI to generate a molecule's formula, 3D atom and bond data, and an educational explanation. It draws the structure on an interactive canvas so you can inspect it from different angles.

## Features

- Enter a molecule name or choose an example: water, caffeine, ethanol, glucose, aspirin, or benzene.
- View the generated formula, molecular structure, and an explanation of geometry, bonds, polarity, and interesting facts.
- Drag the canvas to rotate the structure, use **Rotate** for continuous rotation, and **Reset** to restore the view.
- The Flask server proxies requests to the OpenAI Chat Completions API so the API key stays on the server.

The molecule structure and explanation are generated by an AI model, so results may vary and should be checked against a trusted chemistry source when accuracy matters.

## Requirements

- Python 3.13 or newer
- An OpenAI API key with access to the model configured in `templates/index.html`

## Run locally

1. Create and activate a virtual environment (optional but recommended):

   ```bash
   python -m venv .venv
   source .venv/bin/activate  # Windows: .venv\Scripts\activate
   ```

2. Install the Python dependencies:

   ```bash
   pip install -r requirements.txt
   ```

3. Set your API key in the environment:

   ```bash
   export OPENAI_API_KEY="your-api-key"  # PowerShell: $env:OPENAI_API_KEY="your-api-key"
   ```

4. Start the server:

   ```bash
   python main.py
   ```

5. Open [http://localhost:5000](http://localhost:5000).

The app returns an API error if `OPENAI_API_KEY` is missing. The key is read by the server and should not be placed in the HTML or committed to the repository.

## Project files

- `main.py` — Flask app, page route, and OpenAI API proxy (`POST /api/molecule`).
- `templates/index.html` — Single-page interface, AI requests, canvas renderer, and interaction controls.
- `static/tgalogo.png` — Logo displayed in the page header.
- `requirements.txt` — Python runtime dependencies.

There is no React build step; the interface is served directly by Flask. `package.json` contains placeholder scripts and is not used to run the current app.
